- `POST /contact/{id}/add-interaction/` — add interaction + auto-trigger lead scoring

- Enhanced `GET /opportunity/` with stage/value filters

## New Files Created

These files did not exist in the original generated code and were created entirely for custom features.

### 5. `auth.py` — Authentication Utilities

| Lines | 45 |

- JWT token creation and verification

---

### 6. `scoring_service.py` — Lead Scoring Engine

| Lines | 143 |
|-------|:---:|

- Rule-based lead scoring algorithm
- Scores based on: profile completeness, enrichment status, interaction count/recency, email engagement, opportunity value
- `recalculate_and_save()` — recalculates score and persists to ScoreHistory
- Auto-triggered after enrichment and new interactions

---

### 7. `enrichment_service.py` — LinkedIn Enrichment

| Lines | 134 |
|-------|:---:|

- `enrich_from_linkedin()` — main entry point
- OpenAI GPT-4o integration: sends LinkedIn slug, returns first_name, last_name, job_title, company_name, industry
- Mock fallback when no API key is set (deterministic data from URL slug)
- Markdown code fence stripping for reliable JSON parsing

---

### 8. `email_generation_service.py` — AI Email Writer

| Lines | 117 |
|-------|:---:|

- `generate_email()` — generates personalized email using contact context
- OpenAI GPT-4o integration with customizable instructions
- Template support: uses existing email templates as style reference
- Returns structured `{subject, body}` JSON
- Fallback to raw text if JSON parsing fails

---

### 9. `seed_data.py` — Demo Data Seeder

| Lines | 465 |
|-------|:---:|

- Creates demo user, companies, contacts, opportunities, interactions, tags
- Realistic CRM data: 5 companies, 12 contacts, 8 opportunities, 30+ interactions
- Runs on first startup (checks if data already exists)
- Pre-calculated lead scores for demo contacts
