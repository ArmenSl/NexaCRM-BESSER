# NexaCRM - Enhanced Version

An AI-powered CRM application built on top of code **generated by [BESSER](https://github.com/BESSER-PEARL/BESSER)**, then extended with custom features including authentication, AI lead scoring, LinkedIn enrichment, and an email writing assistant.

> **See also:** The [master branch](https://github.com/ArmenSl/NexaCRM_RawEditor/tree/master) contains the raw, unmodified output from the BESSER WebApp generator.

## From Generated Scaffold to Full Application

This version demonstrates how BESSER-generated code serves as a solid foundation that can be extended with domain-specific features. Starting from the raw CRUD scaffold (master branch), the following features were added:

### 1. Authentication
- JWT-based sign up, login, and logout
- Protected routes with automatic token management
- Shared sidebar layout with user info

### 2. Contact Detail Page
- Full contact profile with avatar, info card, and action buttons
- Interaction timeline with color-coded entries by type (call, email, meeting, note)
- Modal for adding new interactions

### 3. AI Lead Scoring
- Rule-based scoring algorithm (0-100) evaluating interaction recency, frequency, opportunity value, enrichment status, and contact completeness
- Automatic recalculation on new interactions and opportunity updates
- Score history tracking with audit trail

### 4. LinkedIn Enrichment
- Enrich contacts from a LinkedIn URL
- Mock mode (default) for demo purposes
- Proxycurl integration for real data enrichment

### 5. Email Writing Assistant
- AI-powered email generation using Claude API
- Template-based fallback when no API key is configured
- Preview and edit flow before saving

### 6. Sales Pipeline
- Per-stage summary cards (count, total value, avg probability)
- Filters by stage, value range, probability, and owner

## Getting Started

### With Docker (recommended)

```bash
docker-compose up --build
```

- Frontend: http://localhost:3000
- Backend API docs: http://localhost:8000/docs

### Test Flow

1. **Sign up** at `/signup` with email and password
2. **Log in** at `/login`
3. **Create a contact** from the Contacts page
4. **Click a contact row** to open the detail page
5. **Enrich** with a LinkedIn URL (e.g., `https://linkedin.com/in/john-doe`)
6. **Add an interaction** via the modal
7. **Recalculate score** to see the updated lead score and history
8. **Generate an email** — configure, preview, edit, and save
9. **Pipeline page** — view summary cards and filter opportunities
10. **Log out** from the sidebar

### Without Docker

**Backend:**
```bash
cd backend
pip install -r requirements.txt
python seed_data.py          # Populate demo data
uvicorn main_api:app --host 0.0.0.0 --port 8000
```

**Frontend:**
```bash
cd frontend
npm install
npm run dev
```

### Optional Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `JWT_SECRET_KEY` | Secret for JWT token signing | Dev fallback included |
| `OPENAI_API_KEY` | For AI-powered features | Falls back to templates |
| `ENRICHMENT_MODE` | `mock` or `proxycurl` | `mock` |
| `DATABASE_URL` | SQLAlchemy database URL | `sqlite:///./data/Class_Diagram.db` |
